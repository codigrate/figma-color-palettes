<h1 align="center">
Codigrate Color Palettes for Figma
</h1>

A carefully crafted collection of Figma color palettes inspired by nature and iconic cities around the world.
Each palette carries the signature colors of its Codigrate theme as a design tokens file, so the exact
same colors you code with become available everywhere you design.

## Getting Started

Figma imports a named palette through a plugin. The **.tokens.json** files here use the standard
W3C / DTCG design tokens format, so they load in **Tokens Studio for Figma** (free) or any variable-import plugin.

1. Download the **.tokens.json** palette you want to use.
2. In Figma open the **Tokens Studio for Figma** plugin (install it from the Community once).
3. In the plugin's settings enable the **DTCG** token format, then choose **Import** and pick the downloaded **.tokens.json**.
4. Apply the set: the Codigrate colors arrive as color tokens, ready to push to Figma variables or styles.

Each file is a full semantic token set grouped under the theme name (for example `Codigrate Aurora Borealis`):
**Surface**, **Border**, **Text**, **Accent**, **Selection** and **Status** (Info / Success / Warning / Error, each
with a Focused variant), plus an **Accents** group for the theme's decorative colors. Every token carries its
poetic palette name (for example `Polar Night`) as its description, and grouping under the theme name lets
several palettes live side by side without colliding.
